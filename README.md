## ✨ Key Features

### ⚖️ Context-Aware Karma Ledger
- **Not just simple score farming:** Actions are evaluated with rich context (intent, repetition, severity, consent, relationships).
- **Hidden Karma vs. Public Reputation:** Your deeds echo across time, affecting rebirth, world perception, and consequences.

### 🧬 Lineage & The Cycle of Rebirth
- **Death is a transition, not the end:** Characters transition into realm/rebirth mechanics where lineages, deeds, and heirloom items persist.
- **Ancestral Relics & Item Provenance:** Weapons and tools remember their creators, wielders, and significant historical battles.

### 🌐 Cross-Platform (Fabric + Bedrock Geyser)
- **Isolated Custom JSON UI:** Custom modal screens, spiritual book UI, and HUD karma gauges designed for both PC mouse/keyboard and Bedrock mobile/touch/console without overriding vanilla server forms (`/warp`, `/shop`, etc.).
- **3D Handheld Models & Attachables:** Custom 3D items (such as the Karma Tome) fully rigged with calibrated 1st person and 3rd person holding animations.
- **Pure Vanilla Compatibility:** Bedrock players join via Geyser without requiring client-side Java installation.

## 🚀 Installation & Requirements

### For Players (Java Client)
1. Install **Fabric Loader** (v0.19.5 or higher) for Minecraft **26.3**.
2. Download **Fabric API** (Kotlin Runtime is now directly bundled into Magnus Eterno).
3. Place `magnus-platform-<version>-all.jar` into your `.minecraft/mods` folder.
4. Launch the game!

### For Server Administrators
1. Deploy `magnus-platform-<version>-all.jar` to your Fabric server's `mods` folder.
2. (Optional) For Geyser Bedrock support:
   - Ensure **Geyser-Fabric** or **Floodgate** is installed.
   - Deploy `magnus_bedrock_rp.mcpack` to Geyser's `packs/` folder.
3. Configure `config/magnusmod.json` to customize karma thresholds and realm behaviors.
