# 🎮 คำสั่งและการใช้งาน (Commands & Permissions)

รายการคำสั่งทั้งหมดใน Magnus Eterno รองรับทั้งภาษาไทยและอังกฤษ

---

## 👤 คำสั่งสำหรับผู้เล่นทั่วไป (Player Commands)

| คำสั่ง | คำอธิบาย |
|---|---|
| `/karma` | เปิดหน้าต่างตรวจสอบสถานะกรรมและชื่อเสียงของตนเอง |
| `/karma log` | ดูประวัติการกระทำล่าสุดที่ถูกบันทึกลงในบัญชีกรรม |
| `/lineage` | ดูข้อมูลสายตระกูล บรรพบุรุษ และผู้สืบทอด |
| `/meditate` | เริ่มเข้าสู่สมาธิเพื่อฟื้นฟูจิตวิญญาณและเปิดญาณทัศนะ |
| `/realm` | ตรวจสอบภพภูมิปัจจุบันและเงื่อนไขการเปลี่ยนผ่าน |

---

## 🛡️ คำสั่งสำหรับผู้ดูแลระบบ (Admin Commands)

ต้องใช้สิทธิ์ Permission Level 2 ขึ้นไป หรือ OP

| คำสั่ง | คำอธิบาย |
|---|---|
| `/magnus admin karma <player> add <amount> [reason]` | เพิ่มแต้มกรรมให้ผู้เล่นตามเหตุผลที่ระบุ |
| `/magnus admin karma <player> reset` | รีเซ็ตบัญชีกรรมของผู้เล่น |
| `/magnus admin realm send <player> <realm>` | ส่งผู้เล่นไปยังภพภูมิที่กำหนด (Overworld/Nether/End) |
| `/magnus admin reload` | โหลดไฟล์การตั้งค่า `config/magnusmod.json` ใหม่ |
