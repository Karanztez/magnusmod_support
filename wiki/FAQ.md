# ❓ คำถามที่พบบ่อย (FAQ & Troubleshooting)

---

### Q: ม็อดนี้ต้องลงทั้ง Client และ Server หรือไม่?
**A:** ใช่ครับ หากเล่นแบบ Multiplayer เซิร์ฟเวอร์จำเป็นต้องติดตั้งม็อด และผู้เล่น Java ควรติดตั้งม็อดเพื่อมองเห็น GUI และ Texture ทั้งหมด ส่วนผู้เล่น Bedrock สามารถเข้าเล่นผ่าน Geyser โดยที่เซิร์ฟเวอร์โหลด Bedrock Resource Pack ให้ได้

### Q: ตัวละครตายแล้วข้อมูลจะหายหมดเลยหรือไม่?
**A:** ใน Magnus Eterno **ความตายไม่ใช่จุดจบ (Death is a transition)** ตัวละครจะเข้าสู่วัฏจักรภพภูมิและการเกิดใหม่ โดยสายตระกูล ประวัติกรรม และของตกทอด (Heirloom Items) จะยังคงสืบทอดต่อไปในประวัติศาสตร์ของเซิร์ฟเวอร์

### Q: รองรับเซิร์ฟเวอร์ Proxy เช่น Velocity หรือไม่?
**A:** รองรับครับ Magnus ออกแบบระบบส่งแพ็กเก็ตแบบ Cross-Platform ป้องกันการสับสนระหว่าง Client/Server และสามารถทำงานร่วมกับ Proxy และ Geyser ได้อย่างราบรื่น

### Q: หากพบข้อผิดพลาดหรือบั๊ก ควรแจ้งที่ไหน?
**A:** สามารถเปิดรายงานได้ที่ [GitHub Issues ของ magnusmod_support](https://github.com/Karanztez/magnusmod_support/issues) ได้ตลอดเวลา
